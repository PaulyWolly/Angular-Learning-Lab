@defer

@defer is template-level lazy loading — keep the route, delay a heavy subtree until a trigger (interaction, timer, viewport, …). Contrast with route loadComponent on the Lazy Loading lab (whole page chunk).

Live: on interaction

Click or tab-focus the placeholder. Angular downloads the deferred panel chunk, then swaps in @loading (briefly) and the real component.

@defer (on interaction) { } @placeholder { } @loading (minimum 400ms) {

Loading deferred panel…

} @error {

Could not load the deferred chunk.

}

Live: on timer(2s)

No click needed — ~2s after this card renders, the chunk loads.

@defer (on timer(2s)) { } @placeholder {

Waiting on on timer(2s)…

} @loading (minimum 300ms) {

Fetching…

}

Live: on viewport

Scroll until the tall placeholder enters the viewport — then the deferred panel loads.

@defer (on viewport) { } @placeholder {

Scroll me into view to trigger @defer (on viewport)…

} @loading (minimum 300ms) {

Loading as you arrive…

}

@defer vs loadComponent

  • loadComponent — new route, new page chunk (see /routes/lazy).
  • @defer — same URL; only an island of the template loads later.
  • Know the siblings: @placeholder, @loading, @error.
