Setup · Node · NVM · Angular CLI

Before any Angular lab: install a Node version manager (NVM), a supported Node.js LTS, then the Angular CLI. Use the command blocks below in a terminal — copy buttons are on each syntax card.

Roadmap

  1. NVM — switch Node versions without breaking other projects
  2. Node + npm — runtime that runs Angular’s build tools
  3. Angular CLI (ng) — create, serve, and build apps
  4. Run this lab — npm install + npm start

You are on Windows in this workspace. Use nvm-windows there. macOS/Linux use the classic nvm-sh install — both paths are covered.

1. Why NVM (not “one global Node forever”)

Angular 20 expects a modern Node (typically 20 or 22 LTS). NVM lets you install several Node versions and flip between them per project.

2. Install NVM — Windows (nvm-windows)

Download the latest nvm-setup.exe from the nvm-windows releases page. Close and reopen your terminal after install.

3. Install NVM — macOS / Linux (nvm-sh)

Same idea, different installer. After the curl install, open a new shell (or source ~/.bashrc / ~/.zshrc).

4. Angular CLI

The CLI (ng) scaffolds projects and runs the dev server. Install globally while learning, or call it via npx so you never fight global versions.

5. Create & run a new Angular app

Practice the happy path once so ng new / ng serve feel familiar before diving into labs.

6. Run this Learning Lab

Working branch for this repo is dev. Dev server port is 4201 (see package.json).
