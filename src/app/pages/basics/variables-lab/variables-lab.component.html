Use let and const — not  'var'. typeof tells you the runtime type. Angular component fields are the same idea on a class.

Stop using var — use let (or const)

var is old JavaScript. It is function-scoped and gets hoisted in confusing ways. Modern JS/TS (and every Angular app) uses let / const instead — block-scoped and predictable.
