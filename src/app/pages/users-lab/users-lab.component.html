Query params ↔ search

Typing updates /users?q=… (debounced). Opening a shared link like /users?q=leanne seeds the input and filters the list. Empty query removes q from the URL.

Why switchMap on the detail page?

switchMap maps each new user id to a posts request and unsubscribes from the previous one. That prevents stale posts flashing when you click users quickly. The user itself is prefetched by a ResolveFn before the detail activates.
