Data Binding

Binding connects class fields to the template. Learn the four you’ll hear in interviews: interpolation, property, event, and two-way. Each card shows a live demo plus Template and TypeScript syntax.

Interview — standalone: true is optional in v20. Components, directives, and pipes are standalone by default. You can omit standalone: true. Say: “Standalone is the default in v20; I only set the flag if I’m using standalone: false for a legacy NgModule.”

1. String interpolation — double curly braces

One-way: class → template. Change the class field (buttons or the input below) and Angular change detection re-renders {{ curlyDisplayName }} in the DOM.

Hello, {{ displayName }}

2. Property binding — [property]

One-way: set a DOM/property from an expression.

class.on = {{ isHighlight }}
Interview gotcha — booleans need [disabled], not interpolation. {{ disabledInterpExample }} writes the string "false" when the flag is false. In HTML, a boolean attribute that is present still disables the control — so the button stays disabled. Use [disabled]="isDisabled" so Angular sets the real boolean DOM property. Same idea for checked, readonly, etc.

3. Event binding — (event)

One-way: template → class (user actions call methods).

clickCount = {{ clickCount }}    

4. Two-way binding — [(ngModel)]

Banana in a box: property + event together. Needs FormsModule. Change the input and the preview updates; it’s the same field in both directions.
