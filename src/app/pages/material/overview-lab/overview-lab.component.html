Angular Material · Overview & Setup

Angular Material is the official component library implementing Material Design. In modern Angular, each component is standalone — import only the specific Mat*Module pieces you need.

1. Setup Checklist

Three quick steps to configure Angular Material in an Angular app:

1
Install

npm i @angular/material @angular/cdk

2
Animations

provideAnimationsAsync() in app.config.ts

3
Theme & Icons

Prebuilt theme in styles.scss + Material Icons in index.html

2. Buttons & Ripple Effects

Material buttons include built-in hover states, focus management, and ripple animations.

3. Cards (mat-card)

Cards group related information with consistent surface elevation, headers, media, and action buttons.

Angular Material in Action Standalone Components

Material Design components provide accessible, consistent, tested UI building blocks. They work directly with signals, reactive forms, and modern Angular features.
