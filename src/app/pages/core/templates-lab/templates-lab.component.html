Templates

Every component has one view. You either point at a full-page HTML file with templateUrl, or paste the markup inline with a backtick string: template: `...`. Same bindings either way — the difference is where the HTML lives.

Live · inline backtick template

The green box below is a child component whose entire view is defined with template: `...` inside its .ts file — no separate .html. Change the name; the inline view updates with the same binding rules.

When to choose which

  • templateUrl — full lessons, forms with many fields, anything longer than ~15–20 lines. Matches Angular CLI defaults.
  • template: `...` — tiny widgets, teaching chips, one-file demos (see also the Change Detection children in this app).
  • Never set both. Pair styles the same way: styleUrl vs styles: [`...`].
