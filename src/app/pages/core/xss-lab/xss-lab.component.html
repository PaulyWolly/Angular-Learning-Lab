XSS · stay safe in the template

Cross-site scripting (XSS) means attacker-controlled text runs as code in someone else’s browser. Angular helps by default: interpolation escapes HTML, and [innerHTML] is sanitized. The dangerous move is bypassSecurityTrustHtml on user or API strings.
